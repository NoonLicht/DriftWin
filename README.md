# DriftWin

«Бесконечный холст» для окон Windows 11, написанный на Rust. Статус: **эксперимент, Этап 0 (разведка)**.

Вдохновлено [driftwm](https://github.com/malbiruk/driftwm) (Rust + Smithay, GPL-3.0). Код driftwm не копируется:
берутся только идеи, поведение и формат конфигурации/IPC. Лицензия DriftWin — MIT.

## Идея

Окна лежат на бесконечном 2D-холсте в натуральном размере, экран — «камера». Навигация жестами тачпада, мышью и
клавиатурой; привязка и кластеры; правила окон; несколько мониторов; сохранение сессии; IPC/CLI.
Приложение живёт в трее, закрывается в любой момент, при выходе (в том числе аварийном) возвращает окна на экран.
Никаких драйверов, замены оболочки и прав ядра.

## Ограничения (не обещаем)

1. Композитор не заменяется: окна рисует DWM, мы работаем поверх него.
2. Реальное окно нельзя масштабировать без смены размера. «Зум» — режим обзора через DWM Thumbnails (окна в нём
   неинтерактивны). Масштаб ограничен сверху 1.0.
3. Окна процессов с повышенными правами из обычного процесса не двигаются (UIPI) — нужен запуск от администратора
   или `uiAccess=true`.
4. Игры в эксклюзивном полноэкранном режиме, защищённый контент и часть UWP/WinUI двигать нельзя или нежелательно:
   нужны список исключений и автоотключение.

## Безопасность при разработке

Прототипы в `prototypes/` двигают **только собственные тестовые окна**; чужие окна читаются, но не изменяются.
