# DriftWin

«Бесконечный холст» для окон Windows 11, написанный на Rust. Статус: **ранняя версия**, работает на реальных окнах Windows 11.

Вдохновлено [driftwm](https://github.com/malbiruk/driftwm) (Rust + Smithay, GPL-3.0). Код driftwm не копируется:
берутся только идеи, поведение и формат конфигурации/IPC. Лицензия DriftWin — MIT.

## Идея

Окна лежат на бесконечном 2D-холсте в натуральном размере, экран — «камера». Навигация жестами тачпада, мышью и
клавиатурой; привязка и кластеры; правила окон; несколько мониторов; сохранение сессии; IPC/CLI.
Приложение живёт в трее, закрывается в любой момент, при выходе (в том числе аварийном) возвращает окна на экран.
Никаких драйверов, замены оболочки и прав ядра.

## Возможности

- **Камера и навигация.** Плавная камера на критически демпфированной пружине: разгоняется с нуля и мягко
  останавливается; на длинных переездах окна подменяет GPU-оверлей, поэтому нет рывков.
- **Обзор и масштаб.** Живой обзор всех окон (захват WGC на GPU, режим `capture`) с зумом колесом; окна в обзоре
  принимают мышь. Зум до максимума открывает окно на весь экран; справа сверху кнопки «свернуть» (назад в обзор)
  и «закрыть».
- **Окна.** Привязка к соседям и кластеры, перемещение и изменение размера, `fit` / `fill` / полный экран,
  закладки, закрепление окна на экране, прозрачность, правила окон.
- **Фон.** Процедурные фоны без картинок: `aurora` и `fractal` (шейдер), сетка, цвет, плитка, обои и гигапиксельные
  TIFF-пирамиды. Фон рисуется и под обычными окнами (`on_desktop`).
- **Система.** Несколько мониторов, сохранение сессии, IPC и CLI (`driftwinctl`), трей, аварийный возврат окон.

## Ограничения (не обещаем)

1. Композитор не заменяется: окна рисует DWM, мы работаем поверх него.
2. Реальное окно нельзя масштабировать без смены размера. «Зум» — режим обзора через DWM Thumbnails (окна в нём
   неинтерактивны). Масштаб ограничен сверху 1.0.
3. Окна процессов с повышенными правами из обычного процесса не двигаются (UIPI) — нужен запуск от администратора
   или `uiAccess=true`. Такие окна (например, окно настроек RivaTuner) остаются на экране поверх холста.
4. Игры в эксклюзивном полноэкранном режиме, защищённый контент и часть UWP/WinUI двигать нельзя или нежелательно:
   нужны список исключений и автоотключение.

## Безопасность при разработке

Прототипы в `prototypes/` двигают **только собственные тестовые окна**; чужие окна читаются, но не изменяются.

## Быстрый старт

```
cargo build --release
target\release\driftwin.exe --only notepad.exe     # безопасный режим: только окна из белого списка
target\release\driftwinctl.exe msg state           # состояние демона через IPC
```

Конфиг — [config.example.toml](config.example.toml), справка по настройкам — [docs/CONFIG.md](docs/CONFIG.md).
Аварийный выход, возвращающий окна на экран, — Win+Ctrl+Shift+R.
